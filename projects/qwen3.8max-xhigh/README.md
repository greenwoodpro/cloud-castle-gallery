# 云上的城堡 · 浮空岛 3D 场景

用 three.js 手绘的一座中世纪城堡，坐落在一块浮空岛上。整体走《小王子》插画的画风：
低多边形、柔和的 toon 着色、暖色水彩配色，没有写实材质，也没有任何外部贴图——
所有纹理（水面、旗帜、玻璃、光晕）都是运行时用 canvas 程序化生成的。

## 运行

```bash
pnpm install
pnpm dev
```

打开 http://localhost:3000 。

生产构建：

```bash
pnpm build && pnpm start
```

## 操作

| 操作 | 说明 |
| --- | --- |
| 左键拖拽 | 旋转视角（自由视角，OrbitControls） |
| 滚轮 | 缩放 |
| 右键拖拽 | 平移 |
| 点击场景中的编号圆点 | 查看该地点的详细说明，相机自动飞过去 |
| 点击任意人物 | 弹出他的身份与一句话 |

右侧「观看方式」面板可以控制：

- **剖视主堡** —— 四面外墙淡成幽灵轮廓，五层楼板与全部家具露出来
- **放下吊桥** —— 吊桥与吊闸联动开合
- **显示人物 / 显示标注**
- **自动环绕 / 昼夜流转**
- **时刻滑杆** —— 从黎明到深夜，天空、光照、雾色、窗内灯火、灯笼与篝火全部联动
- **高画质** —— 切换像素比与阴影贴图分辨率

## 场景内容

### 浮空岛
上表面是程序化地形（草丘、岩脊、池塘、溪流、城门大道），下表面是倒锥岩体加垂挂根须，
岩层按高度分带着色。岛底有一圈柔光，环绕的碎石以不同速度公转。

### 地形
草地、干草坡、麦田、玫瑰园、村落、市集、训练场、马厩、礼拜堂、池塘、码头、
石桥、瀑布、风车、篝火、秋千、树木、灌木、芦苇、草丛、野花、岩石、篱笆、小径。

### 城堡
八折环形幕墙 + 雉堞 + 走道 + 四座圆塔（两种收顶）+ 城门楼 + 吊闸 + 双扇木门 + 吊桥 + 干壕 + 木平台。

### 主堡（五层，可剖视）
| 层 | 标高 | 内容 |
| --- | --- | --- |
| 地牢与储藏室 | 2.68 | 两间带铁栏的牢房、锁链、酒桶酒架、板条箱、工具台、暗道拱门、鸟笼 |
| 大厅 | 7.03 | 高台与王座（紫色华盖）、两张长桌与长凳、大壁炉、两盏环形吊灯、挂毯与盾牌 |
| 厨房与面包房 | 11.38 | 大灶与吊锅、穹顶面包炉、工作台与面包、垂挂铜锅与香草、转烤架、水桶与奶油桶 |
| 书房与星象室 | 15.73 | 四组书架（逐本生成的书）、写字台与羽毛笔、天球仪、浑天仪、星图、望远镜 |
| 寝室与玫瑰室 | 20.08 | 四柱床与床幔、圆地毯、衣柜、木箱、梳妆镜、窗座靠垫、玻璃罩里的玫瑰、"蟒蛇吞象"挂画 |
| 屋顶平台 | 24.43 | 雉堞步道、木造瞭望亭、望远镜 |

贯穿五层的是 90 级螺旋楼梯，绕中心石柱盘旋，带连续螺旋扶手。

### 人物
小王子、狐狸、绵羊、国王、卫兵、厨师、天文学家、吟游诗人、侍女、商人、点灯人、
牧羊人、村里的孩子、马、厨房的猫，以及绕岛飞行的鸟群。

小王子与狐狸会在白天待在岛上（玫瑰园、寝室窗座），入夜后自动换到屋顶平台。

## 代码结构

```
lib/scene/
  palette.ts     全部颜色常量（水彩配色）
  layout.ts      所有尺寸与标高常量
  utils.ts       批处理合并、圆角盒、拱券、曲线管、布料、程序化贴图、噪声
  island.ts      浮空岛：地表高度函数、岩体、根须、瀑布、碎石、岛底柔光
  terrain.ts     地形与全部环境物件
  castle.ts      城墙、圆塔、城门楼、吊桥、礼拜堂、马厩、村落、市集、训练场
  keep.ts        主堡外壳、楼板、螺旋楼梯、屋顶、剖视淡出
  interior.ts    五层室内家具与陈设
  characters.ts  人物与动物
  sky.ts         天穹、日月星辰、云、远处的小行星（含 B-612）、昼夜光照
  hotspots.ts    24 个标注点的数据与相机机位
  scene.ts       渲染器、相机、控制器、拾取、主循环、对外接口

components/
  castle-viewer.tsx  挂载 three.js 场景并同步 UI 状态
  scene-panels.tsx   全部 UI 面板
```

## 性能

- 所有重复几何体（雉堞、麦穗、书、瓦片、碎石……）都用 `Batcher` 合并成单次绘制
- 阴影隔帧刷新（`shadowMap.autoUpdate = false` + 每 3 帧 `needsUpdate`）
- 不使用任何外部贴图，首屏没有网络请求负担
- 「高画质」关闭时自动降像素比与阴影分辨率
