# 星海上的城堡 · Le Château au Bord des Étoiles

一座漂在星海上的中世纪城堡。用 three.js 手工搭出来的浮空岛、城堡、房间和人物，画风参考《小王子》的水彩插画：暖砂色的石头、雨蓝色的屋顶、低饱和的草地，光很软，颜色很轻。

---

## 怎么打开

浏览器的 ES Module 不允许直接 `file://` 打开，所以需要一个本地静态服务器。三种方式任选：

1. **双击 `启动城堡.bat`**（Windows，需要已安装 Python）。会起一个本地服务器并自动打开浏览器。
2. 在该目录打开终端：
   ```bash
   python -m http.server 8123
   ```
   然后访问 <http://localhost:8123>。
3. 已安装 Node 的话：
   ```bash
   node server.mjs 8123
   ```

推荐 Chrome / Edge / Firefox 的较新版本，需要 WebGL2。

## 视角与操作

- **拖动**：环绕飞行
- **滚轮**：靠近 / 拉远
- **右键拖动**：平移
- 右侧「导览」：15 个点位，点一下就飞过去，并展开这一处的详细文字
- 底部工具条：
  - **自动旋转**：让岛慢慢转
  - **剖切透视**：靠近相机一侧的墙体与屋顶自动淡出，露出室内（可以一边转一边看穿每个房间）
  - **星夜**：黄昏与夜晚之间平滑过渡，窗户、火把、灯笼会亮起来
  - **复位**：回到全岛

也可以用 URL 直接进入某个点位，例如：

```
http://localhost:8123/?spot=hall
http://localhost:8123/?spot=garden
http://localhost:8123/?spot=night&night=1
http://localhost:8123/?spot=overview&cut=1&norotate=1
```

`spot` 可选：`overview`、`gate`、`keep`、`courtyard`、`hall`、`kitchen`、`library`、`solar`、`observatory`、`terrace`、`chapel`、`garden`、`fields`、`waterfall`、`night`。

## 世界：一座岛，三层高度

整座岛像一块被小心托起来的蛋糕，从下往上分成三层：

**岛底**是层叠的岩壁——赭石、玫瑰、淡紫、灰紫，一层压着一层，像一本摊开的旧书；越往下越窄，最后收成一个尖，垂进云海。几块带着草的碎石脱离了岛体，在旁边慢慢飘着。岛缘有细小的草坡和石头。

**岛面**中央是一块微微隆起的石台地，城堡坐在上面。台地之外是缓缓下坡的草地，被一条溪水切成两半：溪水从岛的东边流过来，绕过南面的城墙，在岛缘忽然断掉，变成一道白色的瀑布落进云里。溪上有石桥，桥下有被水磨圆的石子和芦苇。

**岛缘之外**是云海：大团大团的云在岛的下面慢慢漂，远处还有几座更小的浮空岛，每座上面都有一两棵树和一座小小的城堡剪影。

## 城堡外部

城堡是「广义的中世纪欧洲城堡」：有幕墙、角楼、城门楼、吊桥、主堡、礼拜堂和庭院。

### 幕墙与角楼

一圈五米多高的石墙围出 22 × 17.5 的院子，墙顶留一条窄走道，垛口后面可以并排走两个人。墙面每隔几步有一支箭孔，黄昏时从箭孔里透出一点金色。四角各立一座圆塔，塔顶是覆着青灰瓦或陶土色瓦的圆锥，塔尖插着红旗。南墙和东墙上爬着常春藤，墙头插着旗。

### 城门楼与吊桥

南面是唯一的大门。两座圆塔夹着一道尖拱，拱上挂着一面酒红色的纹章旗（金星与王冠），两侧各有一面盾。拱下悬着半升起的铁闸，木门照例是敞开的——这座城堡没什么敌人，门开着只是为了让人进来。门前是一座石桥，桥面铺木板，两侧有石栏和四对灯柱；桥下那道溪水绕过城墙，往岛的边缘去了。桥头蹲着两只石狮。

### 主堡

主堡是城堡里最高的一栋，方形，三层，四角各抱着一座细一点的圆塔。西侧贴着一座螺旋楼梯塔，楼梯像一条盘起来的丝带，从大厅一直绕到露台；每层都开一扇小小的拱门，门里永远有一盏灯。主堡南面的门廊由两根石柱撑着，屋顶压得很低，走进门廊的时候，光线会先暗一下，然后大厅的暖意才扑面而来。

屋顶是可以走上去的露台，四面围着齿状女儿墙，墙角放着三盆植物，一张小圆桌、两把椅子、一瓶没喝完的酒，还有一个火盆和一架旗。从这儿看下去，整座岛摊在脚下。

### 礼拜堂

主堡东侧挨着一座小小的礼拜堂，紫灰色的尖屋顶，侧墙外有一排扶壁，像一排撑着伞的小人。南面是圆形的玫瑰窗，玻璃是暖黄、浅绿和玫瑰色的，下午的太阳斜进来，会在石地上落下一块彩色的光。堂内有祭坛、三联画、两排木椅、圣水盆和一支支直直站着的蜡烛。

### 庭院

城墙与主堡之间是院子，铺着浅色石板，缝里长着细草。院子西头是铁匠铺，炉火正旺，火星一跳一跳；东头是马厩，干草和木头的味道混在一起。水井在中间偏西，木架上挂着一个小桶。市集的条纹布棚下摆着水果和面包，两个孩子绕着井追来追去，鸡在石板缝里找东西吃。

## 城堡内部（逐间）

### 大厅（一层前部）

推开南门就是大厅。地面铺着酒红色的地毯，中间一张五米长的橡木桌，两排长凳，桌上有陶盘、金杯、切开的面包、一盘水果，还有一只烤得正好的鸡。铁链吊着的烛台上有八支蜡烛，风一吹就一起晃。西墙是整面石砌的壁炉，火从早烧到晚，墙上被熏出一层温柔的黑色。大厅北端是一级石台，台上放着高背王座，猩红坐垫，金球做顶。国王陛下站在王座边，权杖拄着地，表情认真得有点可爱——他总觉得自己在统治什么，其实整座岛只有这么一点点大。壁炉边的地毯上，一只老狗睡得正沉。

### 厨房（一层后部）

大厅往北，隔着一道拱门就是厨房。灶台占了整面西墙，拱形灶膛里烧着果木，大铁锅吊在火上，汤咕嘟咕嘟地翻着小泡。北墙的架子上排着陶罐和木碗，屋梁上倒挂着一串红辣椒和几把迷迭香。备菜桌上摊着切了一半的南瓜和一把小刀，地上有木桶、麻袋、一篮鸡蛋和一小堆劈好的柴。厨娘正弯腰看着锅里的火候，一只灰猫蹲在桌角。

### 书房（二层前部）

三面墙都是顶天立地的书架，书脊是褪了色的红、绿、赭、紫，有的歪着，有的被抽走一半。屋子中间一张大书桌，摊着一本没合上的书，旁边是墨水瓶和羽毛笔。窗边有铺了软垫的坐榻，角落里立着木梯和地球仪（海是浅蓝的，陆地像几块不规则的补丁）。地理学家戴着兜帽，捧着书，认真地记录一座他从未离开过的岛。桌上的星图用细线连着星星。

### 卧室（二层后部）

一张四柱床靠着东墙，床柱顶上镶着金球，酒红色的顶篷垂下来，拼布被是淡紫、藕粉、麦黄和浅绿拼的，枕头堆了两层。床脚有木箱，西墙有小壁炉，火压得很低，只为了赶走夜里的湿气。梳妆台上立着一面金框圆镜，旁边留着一支快烧完的蜡烛，窗下放着一双拖鞋。墙上挂着织有城堡、山丘与月亮的挂毯。

### 观星台（三层）

整层都是观星的地方。四面的窗开得又高又大，白天能看见云从岛的下面走过，夜里能看见星。黄铜望远镜架在三脚架上，镜筒斜指着窗外；屋子中间吊着一架太阳系仪，一颗金色的小太阳，四颗小行星绕着它慢慢地转。靠墙有星图桌和浑天仪，铜环一层套一层，像一颗被拆开的地球。角落里有一架木梯通向露台。

### 屋顶露台

风会一下子灌进来：女儿墙、火盆、两把椅子，还有一整片没有人打扰的天空。小王子喜欢站在这里，手背在身后，什么也不做，只是看。他说，从这里数星星最清楚。

### 军械库与城墙走道

庭院西侧有一座棚屋，里面是长矛架、剑架、四面圆盾和一副盔甲。城墙走道上，点灯人举着长杆，把最后一盏灯点亮。

## 人物

- **小王子**：金头发，绿色长外套，黄色围巾在身后飘，站在玫瑰园的草地上，微微仰头。
- **玫瑰**：玻璃罩里的一朵玫瑰，四层花瓣，胭脂到暮色的渐变，花盆下是石台，罩子上有一点雾气。
- **狐狸**：坐在玫瑰旁边，橘色皮毛，白胸脯，大尾巴绕在脚边——它已经被驯养了。
- **国王**：酒红长袍、白鼬斗篷、金王冠、白胡子，站在王座边，手里握着金球权杖。
- **侍从**：紫袍小帽，站在王座另一侧。
- **厨娘**：白围裙、厨师帽、长柄汤勺，弯着腰看灶火。
- **地理学家**：蓝色兜帽长袍，捧着书，在书房里。
- **女仆**：正在收拾卧室的床铺。
- **观星少年 / 点灯人 / 骑士 / 铁匠 / 两个孩子**：分别在观星台、城墙、城门、铁匠铺、水井边。
- **动物**：壁炉边打盹的狗、厨房桌角的猫、院子里的三只鸡、马厩里的马、羊圈里的四只绵羊。

## 岛上的地形与村落

- **西北梯田**：麦子是蜂蜜色，薰衣草是灰紫，还有几块嫩绿的菜地，每一块都镶着矮矮的绿篱，田里有细细的垄。
- **果园**：九棵苹果树排成三行，红苹果小得像纽扣。
- **风车**：立在西边的小丘上，四片帆慢慢地转，白布上补着几块浅色补丁。
- **小村**：南边三座茅草顶小屋，烟囱里冒着细细的烟，门前晾着衣服，篱笆边堆着南瓜。
- **羊圈**：木栅栏围出一圈，四只羊在里面。
- **草甸**：大片低饱和的草地，散着花丛、草簇和石头。
- **玫瑰园**：东边一圈矮绿篱，里面是玻璃罩玫瑰、小王子、狐狸、石凳、路灯和一条石板小径。
- **溪流与瀑布**：绕过城墙，岛缘落下，瀑布底部有水雾和一小片彩虹。

## 环境与光

- **黄昏**：天空从浅蓝过渡到奶油色，太阳在岛的左前方，石头被照成蜂蜜色，阴影是冷的。
- **星夜**：天变成紫蓝色，星星一层层亮起来，月亮从另一侧升起，窗户、火把、灯笼、灶火一起发光。点灯人站在城墙上。
- **云海**：岛下有大团大团的云在漂，远端有小小的浮空岛、飞鸟和一只热气球。
- **动态**：旗子和围巾在风里飘，瀑布在流，水雾在飘，炊烟从烟囱里升起来，风车和太阳系仪在转，光尘在空中慢慢浮。

## 技术说明

- 全部几何体由代码生成，没有外部模型或贴图资源（three.js 已放在 `vendor/`，离线可用）。
- 卡通着色使用 `MeshToonMaterial` + 自定义四级渐变贴图；天空是自定义 shader 的渐变穹顶。
- 剖切透视：每面墙记录它的外法线，逐帧比较相机方向，朝向相机的一侧淡出至 4.5%，因此绕到哪一侧都能看进去；屋顶单独隐藏。
- 昼夜：颜色、雾、半球光、太阳/月光、窗户材质、火光强度、星空透明度一起插值。
- 贴地物体（田野、小路、花园、草簇、花）按解析高度函数 `heightAt(x, z)` 逐顶点贴地，所以不会浮空或陷进坡里。
- 低多边形风格 + 实例化（花、草）、合并思路，桌面浏览器可以流畅运行。

## 性能说明

场景是程序化生成的，早期版本有 4600 多个网格、8040 次绘制调用、18 盏灯，笔记本上会明显发热。现在做了这些优化：

- **静态合批**：所有不变的几何体按材质颜色合并，绘制调用从 8040 降到约 1200；剖切墙、屋顶在组内单独合并，仍能整面淡出。
- **阴影**：投射阴影的物体从 4113 个裁到 182 个（小物件和透明物体不再投影）；贴图从 2048 降到 1024，并改为每 4 帧更新一次。
- **灯光**：从 18 盏减到 11 盏（去掉了月光、岛底补光，以及大厅烛台、壁龛、卧室梳妆灯等几盏小点光）。
- **像素比**：上限从 2.0 降到 1.25，高分屏上像素数少了一半以上，肉眼差别很小。

如果显卡仍然吃力，可以把 `src/main.js` 里的 `renderer.setPixelRatio(Math.min(window.devicePixelRatio, 1.25))` 改成 `1`，或把 `renderer.shadowMap.enabled` 设为 `false`。

`启动城堡.bat` 已改成纯 ASCII 内容，cmd 下不会再出现中文乱码导致的报错。
