## 一、世界观：一块被云托住的土

这不是一座"建在山上"的城堡，而是一整块**被从大地里拔出来、悬在云海之上的土**。岛的下半截是岩，上半截是草，中间夹着七米多高的台地崖壁——城堡就压在那块台地上，像谁把一枚戒指放在了蛋糕顶。

风格取自圣埃克苏佩里的水彩：低饱和的奶油白、灰蓝、藕粉、苔绿；体块圆润，边缘柔；光线是日落前一小时那种"纸面被水化开"的空气感。所有石头都带一点手绘的不匀——那不是贴图，是每个材质里都挂了一条噪波。

## 二、岛：岩、草、水

**岩体**是全岛的骨。它由三十层剖面旋转而成，每两三层之间故意让半径外凸一点，形成一圈圈**岩檐**——从下往上看，能读出"沉积—断裂—再沉积"的年轮。岩体越往下越窄，最后收成一个小小的尖，悬在云上。岩壁上有 14 道竖向岩脊、三圈外凸岩层，颜色在暖褐与冷灰之间交替（`岩体` / `岩体深` / `崖壁` / `崖壁深`）。

**草甸顶面**是一张直径 52 单位的软毯，极坐标网格铺出来，边缘与岩体顶圈严丝合缝。起伏由三层正弦叠加：一层缓（做出丘陵）、一层细（做出被风吹皱的草皮）、再加两处高斯鼓包——西北那座 1.5 米高的小丘上站着风车，东北是一道缓坡。低处偏深、陡坡转苔绿，是逐面上色的。

**台地**：岛心一块半径 12.6 的不规则十八边形台，高 7.4 米，侧面被切成六层颜色不同的岩带，外加三道岩檐和十四道竖脊。台顶是城堡。

**水**：
- 岛东一只半径 4.6 的浅湖，湖盆是凹下去的，水面几乎不反光，只在水线上漂三圈极细的涟漪、几丛芦苇、九片睡莲。湖边一个木码头，系一条小船。
- 溪水从湖的东南缺口溢出，顺草坡滑到岛缘，**在岩唇上断成一挂瀑布**：一条从上到下逐渐变宽的水帘，贴着岩壁往下淌（每一行的半径都按岩体剖面算，所以它真的是"贴着石头"流的），落到半空化成极淡的水雾，坠进看不见底的云海。
- 这是全岛唯一"会动"的地方，也是唯一提醒你脚下是虚空的地方。

**峡谷与桥**：岛南草甸被一道浅峡谷切开（地形函数里直接挖的），一座单孔石拱桥跨过去，桥那头是一片小台地。

**卫星岛**：三座小岩锥悬在岛的四周（一座顶着草皮和小松树），再加三十块悬空碎石，只做尺度参照。

## 三、城堡外部

城堡是**八边形**的，外接半径 10.8，压在台地上。

### 1. 城墙
高 7.6、厚 0.95，墙脚加厚成基座，腰上一道檐口线脚，墙头一列城垛（垛宽 0.6、垛口 0.52，刚好能站一个人），内侧还有一道半人高的矮垛。墙面每隔一段开两支箭孔，转角处爬着几丛藤。四面外墙上挂着玫红与青绿的小旗。

### 2. 角楼（四座）
半径 1.6–1.8，高度各不相同（9.2 / 10.4 / 11 / 12），锥顶分别是青瓦、藕粉、苔绿。檐口一圈托石，塔身两支窄窗透出暖光，最高的两座挂旗。**它们都比主堡矮**——这是刻意压的，好让主堡成为唯一的制高点。

### 3. 门楼（南）
一个 6.6 宽、9 米高的门楼体，正中一条 2.9 宽、4.8 高的半圆拱洞。拱洞是真的有进深的：洞口一圈楔形拱券石，里面是两扇半开的橡木门（带三道铁箍）、一道半降的铁闸门（七根竖栅四根横栅），门楣上一枚金色圆徽。门楼顶上是一圈城垛和一面大旗，两侧各贴一座半径 1.35 的小塔。门前挑出一段**悬在崖上的石台**（带垛口、底下两道扶壁），从这里接大阶梯。

### 4. 大阶梯
沿台地南壁**盘旋而下**的二十二级石阶：从城门落到草甸，外侧一道矮墙，转角处一个石平台。它是城堡与村庄之间唯一的通道——也解释了为什么门要开在崖边。

### 5. 主堡（donjon）
半径 4.2，是全岛最高的东西（含顶 30.6 米）。
- 八角台基 → **C 形石墙**（从 150° 到 390°，正南留出 120° 的缺口）→ 上段收进的塔身（五支高窗）→ 一圈托石 → 五米七的青瓦锥顶 → 金球、旗杆、红旗。
- 外侧六道扶壁，西侧贴一座半径 1.35 的**旋转楼梯塔**（十四米四，锥顶）。
- 缺口两侧是两根壁柱与柱头，像给"剖开的那一面"镶了个画框。

> 这道 120° 的缺口不是省事，是**故意的剖切**：从庭院望进去，正好看见王座厅。

### 6. 主厅（Great Hall）
西侧，5.8 × 4.6，墙高 4.6，玫红瓦双坡顶。
- 朝庭院（+Y）的一整面**是敞开的**：只有四根木柱、四道横梁和半截屋顶——像一间被掀了半张瓦的屋子。
- 远侧实墙上一座石砌壁炉，烟囱从屋脊穿出去，顶上一个石帽。
- 东侧山墙开一扇暖光窗。

### 7. 礼拜堂
东侧，4.2 × 5.4，墙高 5.2，苔绿瓦。
- 正立面（朝庭院）下部是一个 2.7 宽、4.2 高的拱门，上部山墙里嵌一扇**玫瑰窗**（石圈 + 六根窗棂 + 藕粉玻璃，白天透出柔光）。
- 后侧一座小钟塔，塔里一口铜钟。

### 8. 附屋
- **厨房**：西北角，2.7 × 2.3 的灰泥小屋，茅草顶，一根石烟囱。
- **马厩**：东侧，三根木柱撑起的敞棚。
- **铁匠铺**：西墙根，一间石砌小屋，青瓦顶。

### 9. 庭院
半径 10.2 的铺地，三百块随手铺的石板。中间偏南一口**石井**（井栏、井水、两根木柱、一片小瓦棚、一架辘轳），西侧两座**条纹布棚的市集摊**（柜台、腿、货），七只木桶与铁箍，四盏灯柱，东北角一棵圆冠大树。

## 四、城堡内部（三处剖开，可直接看见）

### A. 王座厅（主堡一层，半径 3.4，高 11.8）
- **地**：石地面 + 一条 1.5 宽的红毯，从缺口一直铺到台阶下。
- **台座**：三级石阶，每级 0.18 高。
- **王座**：木座、高背、扶手、红垫，背板上一枚金色圆徽，两侧各一枚金尖；国王坐在上面（紫袍、白须、金冠、权杖）。
- **彩窗**：北墙一扇直径 2.1 的圆窗，藕粉玻璃，嵌三块青、暖、玫的玻璃块，是厅里唯一的光源方向。
- **柱**：四根石柱（柱础、柱身、柱头），撑起二层廊台。
- **廊台**：沿墙一圈木廊（内半径 1.95），抬头能看见它的底。
- **陈设**：两幅挂毯（青、玫）、两座火盆（真有火苗与点光）、一盏八烛铜环吊灯、一张摊着地图的小桌、两支长矛的卫士（左右各一）、一道沿墙盘旋而上的木梯。
- **光**：一盏暖色聚光从顶上打下来，只照亮王座那一小块。

### B. 主厅（Great Hall，6.8 × 5.2 的可用空间）
- **地**：木地板（十四道拼缝）+ 一条红毯。
- **壁炉**：石砌炉体、深色炉膛、炉台、炉罩，柴堆上五簇火苗（自发光）+ 一盏暖色点光；炉上一幅青绿织物画，金框。
- **长桌**：3.3 × 1.0，两侧长凳；桌上四组陶盘（两面各四只）、两只黄铜杯、一只青绿酒壶、一只面包、两座烛台；主位是一张高背椅。
- **三位食客**：坐成一排，背对门口——一个赭黄、一个玫红、一个青绿。
- **吊灯**：铜环八烛，从梁上垂下来，是全厅的视觉中心。
- **北墙**：两幅挂毯（玫红、青绿）+ 金杆；西墙三层书板、三十三册书（红/青/金/紫四色书脊）。
- **角落**：一口酒桶、一只木箱、一副甲胄架（胸甲、头盔、长矛）、壁炉边趴着一条狗。
- **结构**：敞开一侧的四根木柱与四道横梁露在外面，抬头能看见椽子与半坡屋顶——剖切本身就是布景。

### C. 礼拜堂（4.2 × 5.4）
- **祭坛**：石台 + 白布 + 两支蜡烛 + 一枚金十字；坛后一幅青绿祭坛画（金框）。
- **圣龛**：北墙一个壁龛，里面一尊奶白色圣像。
- **长椅**：三排，左右各一条，中间留 0.8 宽的走道，走道上一条红毯。
- **光**：玫瑰窗在地面投下一块粉色的光斑；一盏四烛铜环吊在中间；一位修士站在走道边。

### D. 厨房
灶台、炉膛、吊锅、三只木桶、五束倒挂的草药、一张厨台。

## 六、村庄与田园（岛南）

- **七栋半木构民居**：石基、灰泥墙、木构架（立柱、横梁、斜撑）、双坡顶（藕粉三、青瓦二、苔绿二）、烟囱、木门、石阶、两扇窗（暖光）、窗下花箱（四朵小花）。每栋都按地形高度自动落位。
- **村广场**：铺地 + 一口井（井栏、井水、木柱、茅草棚）+ 两座市集棚（玫红/青绿条纹，柜台上摆着果蔬）。

- **石拱桥**：跨峡谷，七块拱石、两道石栏、两个桥头墩。
- **风车**：西北小丘顶上，塔身从 1.55 收到 1.05，环廊八柱、锥顶、四片带布帆的叶轮。

- **湖码头**：木板台、四根桩、一条小船、一支桨。

## 八、环境与光

- **天穹**：不用天空球，直接用 World 节点——把视线方向归一化后取 Z，过一条九段色阶：天顶深靛（`#2E2A4C`）→ 雾紫 → 地平线一圈暖奶油（`#F6CDB4`）→ 往下重新转冷。因为相机总是略微俯视，画面里看到的其实是"地平线以下"那段，所以特意把它做成冷的雾紫，让整块岛从背景里浮出来。
- **星**：320 颗自发光小 icosphere，撒在天球上半部，半径 320。
- **月**：半径 24 的自发光球，外加三层极淡的月晕。
- **云海**：46 组云，每组 3–6 个压扁的球，压到岛下 −14 至 −46 的高度，越远越淡；另有 30 块悬空碎石与三座卫星岛。
- **光**：
  - 主阳（暖，5.4）：从岛的左前上方来，给长而软的影子；
  - 天光（冷，0.75）：从右后上方补冷调；
  - 轮廓光（玫，1.5）：从背后擦出边缘；
  - 两盏大面积补光（900 / 700）压住暗部；
  - 场景里另有 12 盏小点光/聚光：壁炉、火盆、烛台、门火、路灯、提灯、王座顶光、厅内补光。
- **调色**：Standard 视图变换（不用 AgX，保住粉彩的明度），曝光 +0.05，EEVEE 64 samples，1600×1000。

## 九、视角与操作

**九台相机**（都挂在 `视角旋转台` 这个空物体下，各自有自己的焦点空物体，所以环绕时构图不变）：

| 相机 | 内容 |
|---|---|
| `CAM_全景` | 主视图：整座岛 + 城堡 + 村庄 |
| `CAM_城堡` | 城堡 3/4 特写 |
| `CAM_内景` | 站在庭院里看进王座厅 |
| `CAM_剖视` | 主厅敞开面的正面剖视 |
| `CAM_城门` | 从草甸仰望门楼 |
| `CAM_村庄` | 村庄与台地崖壁 |
| `CAM_低角` | 从云海下方仰看整块浮岛 |
| `CAM_俯瞰` | 正上方俯视 |
| `CAM_瀑布` | 瀑布与岩壁 |

**自由视角**：
1. 在 Outliner 里选中 `视角旋转台`，按 `Alt+R` 归零可回到初始方位；直接旋转它，九台相机一起绕岛转。
2. 时间轴 1–240 帧已打好关键帧（绕一圈），直接播动画即可得到环绕镜头。
3. 任意相机都可以直接移动；`TRACK_TO` 约束会保持它看向自己的焦点空物体（`焦点_CAM_xxx`），改焦点即可改构图。

**渲染**：`F12` 即用当前相机出图；分辨率、采样、色彩管理都已设好。

## 十、技术备注

- **桥接**：`mcp-for-blender`（`127.0.0.1:9876`），逐条 `execute_code` 下发；生成脚本在 `src/`，`build.py` 一条命令整体重建（约 20 秒）。
- **建模**：全 `bmesh` 直建，不调 `bpy.ops`（除了最后 `join`/`render`/`save`），所以快且可复现。
- **材质**：Principled BSDF + 噪波色斑（水彩不匀）+ 沿世界 Z 的 Wave 石缝（所有构件的石缝在同一坐标系里对齐，不会每块石头各走各的）。
- **合批**：草、花、碎石、树、鸟、云、星等装饰都合进单一网格，把 1300 个对象控制在可交互的量级。
- **可复现**：随机种子固定（77 / 515 / 4242 / 2026 / 3131 / 808），每次重建结果一致。
