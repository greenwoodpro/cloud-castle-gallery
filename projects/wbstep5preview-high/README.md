# 云端城堡 · 小王子风格浮空岛（three.js）

一个完全程序化生成的中世纪欧洲城堡 3D 场景：城堡矗立于浮空岛之上，
小王子水彩画风，自由视角，内置剖视结构、昼夜交替、环绕浮空群岛与人物图鉴。

## 打开方式

- **直接双击 `index.html`** 即可在浏览器中打开（页面通过 CDN 加载 three.js r160，需联网）。
- 若需**完全离线**运行：`lib/` 目录已内置 three.js 与扩展库，将 `index.html` 中
  importmap 的三行 https://cdn.jsdelivr.net 地址改为相对路径，再经本地静态服务器打开
  （ES Module 不能通过 file:// 加载本地文件），例如：

  ```json
  {"imports": {"three": "./lib/three.module.js", "three/addons/": "./lib/"}}
  ```

  ```bash
  cd floating-castle && python -m http.server 8080
  # 浏览器访问 http://localhost:8080
  ```

## 操作

- 左键拖动旋转 · 滚轮缩放 · 右键平移
- 点击场景中的名字标签，或右侧「人物志」中的「飞过去看看」按钮飞向对应角色
- 工具栏：剖视城堡（打开内部结构）/ 人物标签 / 自动环绕 / 时刻（黄昏→晨曦→星夜）/ 回到全景

## 内容一览

- 城堡：城墙与四座角楼、门楼与吊桥、主堡三层（王座大厅、图书角、观星台）、
  礼拜堂（彩窗与钟楼）、厨房、马厩、内院（老井、许愿喷泉、小货摊）、火盆与地牢老猫彩蛋
- 人物：小王子（自动巡逻）、玫瑰、狐狸、卫兵兄弟、国王、点灯人、地理学家、羊群
- 地形：草甸花海、月牙湖与瀑布、沙洲、悬崖与倒生岩锥、碎石小径、玫瑰园
- 环境：环绕浮空群岛（玫瑰岛/国王岛/灯夫岛/地理学家岛/火山岛/猴面包树岛/风车岛）、
  云海、星空、流星、飞鸟、蒲公英、萤火虫、烟柱与瀑布水雾

`qa/` 目录内为无头浏览器渲染验证截图，可快速预览效果。
