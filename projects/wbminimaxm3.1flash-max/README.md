# 浮空岛上的城堡 · Le Château Flottant

一个用 three.js 搭建的中世纪欧洲城堡 3D 场景，坐落在浮空岛上，画风参考圣埃克苏佩里的《小王子》绘本。

## 运行方式

场景用 ES Module + importmap，**必须通过 HTTP 打开**（直接双击 index.html 会被浏览器的 CORS 策略拦截）。

```bash
# 在 castle/ 目录下起一个静态服务器
python -m http.server 8848
# 然后浏览器访问 http://127.0.0.1:8848/index.html
```

three.js r160 已放在 `vendor/`，**完全离线可用**，不需要联网。

## 操作

| 操作 | 效果 |
|---|---|
| 左键拖拽 | 环绕旋转 |
| 滚轮 | 缩放 |
| 右键拖拽 | 平移 |
| 点击金色标签 | 弹出该地点的详细注释，同时镜头自动飞过去 |

左侧面板提供 8 个视角预设、昼夜切换、剖视模式、注释开关、自动旋转和自动巡览。

## 场景内容

### 城堡结构（广义中世纪欧洲）

- **外墙**：四段石砌幕墙，墙高 9.2 米，墙顶步道设雉堞，外侧有扶壁与箭窗
- **角楼**：6 座圆形塔楼，锥形陶瓦顶，顶部旗杆挂旗，夜间塔顶燃起篝火
- **主堡（Donjon）**：三层方形主楼，高 24 米，顶层四角小楼
  - 底层 **地牢**：三间铁栏隔间、锈链锁具、火把
  - 二层 **大厅**：长桌与长凳、王座、鎏金冠饰、壁炉、三座烛台、织锦挂毯
  - 三层 **寝宫**：四柱大床、书架、书桌、地毯、火盆
  - 顶层 **瞭望台**：火盆、望远镜
- **大门**：双塔夹峙的拱形门洞，上方守备室带彩窗，铁闸门，放下的木吊桥，门外石引桥与桥墩石狮
- **大礼堂**：西侧长厅建筑，高挑山墙屋顶
- **礼拜堂**：东侧小教堂，彩色玻璃窗，尖顶金十字
- **铁匠铺 / 马厩**：带烟囱的矮屋与茅草顶木棚
- **庭院**：水井（辘轳木桶）、劈柴堆、干草垛、训练假人、三顶市集摊位

### 人物

小王子（城垛上，金发红围巾）、玫瑰（玻璃罩下）、狐狸、国王（紫袍金冠）、商人（背包数钱）、农夫、士兵、女孩、学者、点灯人（夜巡带灯）、守门人、瞭望人、牧羊人。

### 地形与生态

浮空岛半径 76，底部为倒悬水滴状岩体，垂挂石柱与藤蔓；岛面包含草皮台地、湖（东侧，湖水从崖顶倾泻成瀑布）、麦田、菜园、玫瑰园、松林与圆叶林混交带、农舍群、风车、羊群栅栏、石路网络。

### 环境

程序化渐变天穹（带太阳辉光与地平线暖带）、1500 颗星星、10 朵漂移的云、3 颗远处小星球（含 B-612 式的小树与玫瑰）、9 只盘旋飞鸟、夜间 220 只萤火虫。昼夜切换会同步改变光照、天空、雾、窗内烛光与月相。

## 技术要点

```
castle/
├── index.html      # UI 外壳、绘本风格样式、importmap
├── src/
│   ├── main.js     # 场景组装、相机、昼夜、剖视、标签系统
│   ├── world.js    # 天空、星星、浮空岛、湖与瀑布、树、云、道路
│   ├── castle.js   # 城堡全部构件与内部陈设
│   ├── people.js   # 人物、狐狸、玫瑰、羊、马、点灯人
│   ├── scenery.js  # 农庄、麦田、菜园、森林、羊群、栅栏
│   ├── textures.js # 程序化 Canvas 贴图（石、瓦、木、草、水、织物）
│   └── util.js     # 噪声、色彩、网格辅助
└── vendor/         # three.js r160 + OrbitControls（本地离线）
```

**剖视模式**（🔍 按钮）：屋顶与朝相机的外墙淡出、主堡楼板转为半透，可纵向看穿三层结构。

**贴图着色约定**：所有程序化贴图本身即最终颜色（草是绿的、石是奶油色、瓦是陶红），材质 `color` 保持白色，避免 `map × color × vertexColor` 三重相乘导致画面发暗发浑。

**UV 约定**：`box()` / `cyl()` / `coneRoof()` / `gableRoof()` 会按构件的世界尺寸重算 UV，保证砖块与瓦片在所有构件上物理尺寸一致，不会被拉伸成巨大色块。

## 性能

约 1900 draw call、13 万三角面、30 张程序化贴图。阴影为 2048 PCFSoft。若需在低配机器上跑，可把 `renderer.setPixelRatio(Math.min(devicePixelRatio, 2))` 改为 1，或调低 `sun.shadow.mapSize`。
