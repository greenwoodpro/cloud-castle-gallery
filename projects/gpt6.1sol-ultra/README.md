# 云端城堡 · 风住的地方

一个使用 Three.js 制作的原创童话浮空岛。中世纪欧洲城堡、半木构村落、金色麦田、松林与瀑布，被放在柔和的纸色天空里。画面采用温暖低饱和配色、细小的生活道具和轻缓动画，表达《小王子》般宁静、富于想象的气质。

这是保存在本地的新项目。模型、动画、人物和环境音都由代码直接生成，不需要 AI 服务、API 密钥、账号或外部模型素材。

## 启动

Windows 可以直接双击本文件夹中的 `启动城堡.cmd`，会启动本地服务并打开浏览器。游览时保留启动窗口，结束后按 `Ctrl+C` 停止。

需要 Node.js 22.12 或更新版本。首次安装依赖需要联网。

```powershell
cd "D:\OneDrive\Desktop\云端城堡\codex6.1ultra\chateau-in-the-clouds"
npm install
npm run dev
```

在浏览器打开终端显示的地址，通常为 `http://127.0.0.1:5173`。如果这个端口已被占用，Vite 会显示实际使用的端口。

Windows PowerShell 若阻止运行 `npm.ps1`，可在同一目录改用 `npm.cmd install` 和 `npm.cmd run dev`。

需要支持 WebGL 2 并开启硬件加速的现代浏览器。推荐新版 Edge 或 Chrome。请通过 HTTP 服务打开项目；直接双击 `index.html` 无法加载 ES 模块与开发源码。

## 这座小王国里有什么

- **城堡建筑**：奶油色石墙、城门、庭院、尖顶塔楼、垛口、拱窗、旗帜，以及楼层之间的空间关系。屋顶与部分外墙可以打开，观察室内家具。
- **城堡内部**：公共宴会厅、藏书室、上层寝室和厨房，使用长桌、座椅、书架、床铺、炉灶和储物道具描述生活用途。
- **村落与农田**：半木构小屋、石井、菜畦、木栅栏、麦田和会转动的四叶风车，曲折小径把各处相连。
- **浮空地貌**：连续草甸、草坡、松林、阔叶树、岩石、野花，以及向下收拢的层状岩体和露出的树根。
- **水系与天空**：蜿蜒溪流、木拱桥、岛缘瀑布、水面涟漪、缓缓移动的云、远处的小浮岛和夜空星光。
- **八位居民**：旅人里昂、观星人阿德里安、园丁艾拉、面包师玛尔塔、牧羊人诺埃、守书人塞西尔、守门人奥斯卡、小画家露西，各有服饰、随身道具与原创故事。
- **小动物**：戴铃铛的绵羊、松林边的狐狸、盘旋的飞鸟和低飞的蝴蝶。

这是供自由观察的故事场景。人物轻微呼吸，飞鸟、蝴蝶、风车、溪流和云层持续运动。内部以剖视方式欣赏，视角使用轨道控制。

## 构建与本地检查

```powershell
npm run build
npm run verify
npm run preview
```

生产文件输出到 `dist/`。第二个命令通过本地 HTTP 服务预览构建结果，通常使用 `http://127.0.0.1:4173`。可以将 `dist/` 放到支持静态文件的 Web 服务根目录；若部署在子路径，请先在 Vite 中配置相应的 `base`。

## 文件结构

```text
index.html          页面结构、手记容器与操作指南
src/main.js         相机、灯光、交互、手记、昼夜、环境音与明信片
src/castle.js       城堡外观、内部房间、剖视对象
src/landscape.js    浮空岛、村落、田野、树林、溪流和瀑布
src/life.js         人物、小动物及其动画与故事元数据
src/style.css       纸色界面、中文排版与响应式布局
favicon.svg         本地图标
```

模型使用共享几何体与材质，大量花朵、麦穗和树木部件使用实例化绘制。依赖通过 `package-lock.json` 锁定，安装后 Three.js 和 Vite 从本地依赖加载。

`npm run verify` 检查模型在多个动画时刻的变换、几何坐标、包围盒、实例矩阵、剖面对象及元数据。它不替代浏览器中的视觉检查。

字体使用本机 Noto Serif SC、系统宋体（Songti SC / SimSun）与系统中文字体，不会发起远程字体请求。场景本身不依赖远程贴图、图片、音频或模型下载。
