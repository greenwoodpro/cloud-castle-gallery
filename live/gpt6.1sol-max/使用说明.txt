云间之境 · 浮空城堡

一、直接欣赏
解压后，用 Chrome、Edge、Firefox 或 Safari 打开「离线展示.html」。
Three.js、全部几何数据与所需中文字体已经打包到 HTML 中，不需要联网、不需要安装依赖、不需要本地服务器。浏览器需要支持 WebGL 并启用硬件加速。

二、自由探索
左键拖动旋转，滚轮缩放，右键拖动平移。触屏单指旋转，双指缩放与平移。
切换「城堡内部」查看三层真实建模的房间；切换晴日、黄昏和星夜；通过下拉菜单飞往五个地点。
空格键切换自动环游，R 键重置视角。「世界手记」记录了建筑、人物、地形与环境。

三、模型文件
models/cloud-castle.glb：完整浮空岛、城堡外观、内部房间、人物、植被、小镇、瀑布和云。内部房间位于外墙后，在建模软件中隐藏 castle-cutaway 和 castle-towers 即可查看。
models/castle-interior.glb：已经移除遮挡外墙、屋顶和外塔的剖面版本。
两个模型均可导入 Blender、Three.js 及支持 glTF 2.0 的软件。GLB 是静态模型；风车、旗帜、云朵的动态效果由展示程序实时驱动。

四、项目源码
source 包含完整 Next.js + React Three Fiber 项目，以及 offline 独立 Three.js 展示源码和打包脚本。建议通过 GitHub 导入 Vercel，或在本地使用 pnpm 安装依赖后运行。
构建命令会重新生成离线 HTML、GLB 与 ZIP；不含任何密钥或私人数据。

本作品为程序化创作的童话微缩世界，并非历史建筑的测绘复原。
